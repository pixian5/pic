# 本轮修复记录

- 裁剪框使用的是翻转 `NSView` 的左上角坐标，`CGImage` 裁剪使用左下角坐标；转换时需要反转 Y 轴。
- 删除首次确认只在 `trashItem` 成功后持久化，避免权限或文件系统错误消耗确认状态。
- 安全书签解析返回目标目录书签解析后的路径；父级书签只提供访问权限，不替换请求的子目录路径。
- 目录扫描同时检查扩展名和 `isRegularFile`，避免把同名目录加入图片列表。
- “铺满窗口”按完整适配窗口处理，图片长宽都不能超过窗口长宽，避免默认显示时裁边。
- 打开大图时，目录枚举与排序移到后台，先显示用户请求的文件；ImageIO 在后台生成最多 4096 像素的首屏图，切换到原尺寸或放大时再按需解码全分辨率，避免主线程重复解码造成秒级卡顿。
